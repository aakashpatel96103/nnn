# 03 — Viral script (Hinglish)

Skills: viral-hook-writer, hook-generator, write-script, reels-scripting, humanizer, on-screen-text-writer.

## Shape (15–30 s, 4–6 spoken lines, ~2.6–3 words/second)
| # | Line | Job | Example (from the reference reel, 18 s) |
|---|---|---|---|
| 1 | Hook (0–3 s) | the promise + proof of "me" + "you too" | Claude ke saare AI models main FREE mein use karta hoon, aur tum bhi kar sakte ho! |
| 2 | How (simple) | the one thing needed | Bas ek API key chahiye aur tum bhi Claude ke different models ko access kar sakte ho! |
| 3 | Bridge to CTA | the value they get | Agar tum bhi ye setup karna chahte ho, toh main tumhe API key aur complete setup guide share kar dunga! |
| 4 | CTA | comment WORD → DM | Toh comment karo "CLAUDE" aur main tumhe API key ka link DM kar dunga! |

Longer reels add 1–3 "proof/step" lines between 2 and 3 (each = one scene with one visual beat).

## Hook rules
- First 3 words carry the topic name or the money/time word. No "Hi guys", no intro, no "aaj hum".
- Specific > generic: "saare models FREE" beats "AI free me".
- Write 3 hooks of different types (claim / secret / question / contrarian / number). Recommend one with a reason.

## Line rules
- Spoken Hinglish: "main", "tum", "toh", "bas", "ekdum". English for tech words. Max ~18 words per line.
- One line = one idea = one scene (or half a scene). Each line must be sayable in one breath.
- Every claim true (see research.md). No "100% guaranteed", no fake numbers.
- CTA word: ONE capital word tied to the topic (CLAUDE, GUIDE, CURSOR). Same word on screen in the comment box.

## What to show the user for approval
```
HOOKS (pick one):  A) ...  B) ...  C) ...   ← my pick: A because ...
SCRIPT (one line per line):
1. ...
2. ...
CTA WORD: CLAUDE   DM resource: API key link
SCENES: 1 model picker + FREE chips | 2 API key card | 3 setup guide checklist | 4 comment box → DM
LENGTH: ~18 s
```
Wait for "ok/haan". After approval the script is frozen: `inputs/script.txt`, one spoken line per line.
