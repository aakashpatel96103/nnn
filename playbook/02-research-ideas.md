# 02 — Topic → research → angle

Use when the user gives only a topic, a link or "kuch viral banao".

1. **Clarify the topic in one line.** If the topic is broad ("AI tools"), propose 3 specific angles and ask:
   e.g. "Claude free me kaise use kare" / "5 free AI tools jo ChatGPT se better hain" / "Cursor ka hidden setting".
2. **Research (real sources only).** Web search + official docs/pricing pages + GitHub. Note for every claim:
   source URL and date. Check: is it really free? limits? signup needed? India available? still true today?
   Save to `projects/<slug>/research.md`. If you cannot verify a claim, drop it or say "approx".
3. **Angle that travels** (skills: going-viral, virality, find-ideas, trend-spotter):
   - Money/time saved ("₹1700/month bachao"), secret/hidden ("ye setting koi nahi batata"), easy win ("2 minute me"),
     identity ("students ke liye"), FOMO on a new release.
   - One reel = one promise. Not a list of ten things unless the format is the list.
4. **Proof to show on screen.** What real UI will prove the promise? (pricing page, model picker, settings,
   GitHub stars, terminal). Ask the user for screenshots/recordings of it, or tell them exactly what to capture.
   If they can't, rebuild the UI faithfully from the official site screenshots you can describe — never fake numbers.
5. **CTA resource.** What will they DM? (guide PDF, link, prompt pack). Ask if unknown — the CTA word depends on it.
