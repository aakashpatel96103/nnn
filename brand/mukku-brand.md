# @mukku.tech brand

- **Handle:** @mukku.tech (end card: avatar `brand/avatar.png` + handle pill + blue Follow → grey "Following" click)
- **Niche:** AI tools, free tech hacks, setups, "kaise use kare" — for Indian students/creators/devs.
- **Language:** Hinglish (Hindi in Latin script + English tech words). Friendly elder-brother tone: "main", "tum", never "aap".
  Short, punchy, spoken — not written. Tech names exactly spelled (Claude, API key, GitHub).
- **Promise of every reel:** one concrete useful thing, mostly free, shown on real UI.
- **CTA pattern:** `Comment "WORD" aur main tumhe <resource> DM kar dunga!` (WORD = one caps word tied to the topic).

## Type
- Headline: Segoe UI 700, 88–100px, letter-spacing −2px, centered, 2 lines max; one accent word in *Georgia italic* clay.
- Labels / chrome: Cascadia Mono 600, 22–24px, uppercase, `// 01 — TOPIC` breadcrumb, `01 / 04` counter.
- Captions: Segoe UI 800, 60px, white pill, spoken word turns ink, unspoken grey, keywords clay.
- Stickers: 800 30px, white with 3px ink border + hard 5px shadow, rotated ±3–6°; green (`.stk.g`) and clay (`.stk.o`) variants.
(Fonts are Windows system fonts; on Mac/Linux the fallbacks Arial/Times/Consolas are close enough — or install them.)
